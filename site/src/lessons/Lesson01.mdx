## What ROS gives you

<RosToolbox />

The idea that holds it together is small: split the software into many small programs, called **nodes**, each with one job, and let them exchange messages over named channels. Lesson 2 is about that structure in detail. Everything else, the tools and the shared packages, works because every ROS program follows the same conventions.

## ROS 1, ROS 2 and Jazzy

<ReleaseTimeline />

There are two generations. ROS 1 started in 2010 and is what much older code and many papers use. ROS 2 is a redesign that removed ROS 1's central server and made communication more robust and configurable (Lesson 16 compares them). Within ROS 2, each **release** has a name, and its first word is what you type: `jazzy`.

## Sourcing: telling a terminal where ROS is

Installing ROS puts its files in `/opt/ros/jazzy`, but a terminal does not know they are there until you **source** the setup file. In a terminal where that has not happened:

<Terminal run={[r['fresh-ros2'], r['fresh-ros-vars']]} />

Sourcing prints nothing. It changes the terminal's settings:

<Terminal run={[r['fresh-source'], { ...r['fresh-after'], command: 'printenv | grep ^ROS | sort' }, { ...r['fresh-which'], command: 'which ros2' }]} />

<SourcingFigure />

<PlainWords>

Sourcing is like giving one terminal a map to ROS. The map belongs to that terminal: open a new one and it has none. On your own computer you add the line to `~/.bashrc` so every new terminal sources it by itself. In the course container that is already done, so its terminals start ready.

</PlainWords>

<Recap>

- **ROS** is communication, client libraries, tools and shared packages, running on an ordinary operating system. It is not an operating system itself.
- Robot software in ROS is many small programs, **nodes**, that exchange messages. Stopping one leaves the others running.
- **ROS 2** replaced ROS 1, which ended in May 2025. This course uses **Jazzy**, a long-term release supported until May 2029, on Ubuntu 24.04, in a container.
- **Sourcing** `/opt/ros/jazzy/setup.bash` sets variables in the current terminal so it can find ROS. Each terminal needs it, so it usually goes in `~/.bashrc`.
- `ros2 run <package> <program>` starts a node. `ros2 --help` lists everything else `ros2` can do.
- Next: what the graph of nodes looks like, and how to inspect it.

</Recap>
